## 문서 작성 언어

프로젝트 문서의 설명과 기록은 한국어로 작성합니다. 기술 용어는 필요할 때 영어를 병기할 수 있지만, 일반 설명은 한국어를 우선합니다.

## 목적

- 세션이 바뀌어도 프로젝트 지식을 보존합니다.
- 주요 의사결정과 구현 이력을 기록합니다.
- 디버깅과 기능 작업이 실제 시스템 맥락에 기반하도록 합니다.
- 무엇이 왜 변경되었는지 명확한 기록을 유지합니다.
- 비즈니스 도메인과 엔지니어링 작업 전반의 시스템 흐름을 보이게 합니다.
