# 59단계: 임차인과 대시보드의 수납 기준 통일

## 변경 이유

임차인 마스터의 `status` 값은 특정 청구월과 연결되지 않아 `납부 완료`, `연체`,
`미납`을 실제 업무에 사용할 수 없었다. 이 값은 과거 결제 기능과의 호환성을
위해 남아 있지만 월별 수납 판단의 근거가 될 수 없다.

## 변경 내용

- 임차인 관리 폼에서 납부 상태 선택을 제거했다. 생성 요청은 이름, 속성, 호실,
  월 임대료만 전송한다.
- API는 새 임차인에 호환용 `Pending` 상태를 기록하고, 외부의 상태 변경 입력은
  무시한다. 월별 수납 상태는 `monthly_charges`와 `payment_allocations`로만 판단한다.
- `/tenants?billingMonth=YYYY-MM` 화면은 선택 월의 청구, 납부, 미수, 상태를
  임차인별로 표시한다. 청구 대상이 아닌 임차인은 `청구 없음`으로 명확히 구분한다.
- 기본 대시보드는 실제 `GET /billing-summary?billingMonth=YYYY-MM`을 사용하며,
  모든 수납 지표는 해당 월의 `/payments` 원장으로 연결된다.
