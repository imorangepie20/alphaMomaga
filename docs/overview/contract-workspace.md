# 계약 운영 화면 개선

## 원인

기존 계약 화면은 갱신 검토·만료 임박 집계 기간이 보이지 않고 검색과 필터가 없었다.
`Active` 상태와 종료일 상한만 검사하여 실제 계약 기간 밖의 레코드도 지표에 포함할 수 있었다.

## 변경

- 서울 기준일을 서버에서 한 번 생성해 지표와 클라이언트 표시가 같은 날짜를 사용한다.
- 유효 계약은 `Active` 상태이며 시작일 이상, 종료일 이하인 계약이다.
- 갱신 검토는 유효 계약 중 120일 이내, 만료 임박은 30일 이내 종료하는 계약이다. 경계일을 포함한다.
  두 지표가 중복되는 범위를 안내하며 상단은 전체 계약을 기준으로 유지한다.
- 임차인·자산명·호실 검색, 자산·상태·갱신 검토·만료 임박 필터를 추가했다. 만료 임박을 먼저 보여주고
  종료일 및 ID 순으로 정렬한다. 계약 기간 아래에는 남은 일수 또는 기간 종료를 표시한다.
- 계약·임차인·자산 조회는 `getContractsWorkspace`를 사용하며 실패하면 오류와 재조회 링크를 표시한다.
  예시 데이터를 실제 운영 데이터에 섞지 않는다.
- 기존 등록·상태/해지일 수정·갱신 API를 유지한다. 변경 요청 중 재제출과 모달 닫기를 차단하고
  모달 높이를 화면 안으로 제한한다. 갱신 가능 표시의 기준일도 서버에서 전달한다.

## 검증과 한계

- 웹 테스트 94개 통과. 30일·120일 경계, 과거·미래·해지 계약 제외, 검색/필터, 일부 조회 장애를 검증했다.
- 변경 파일 ESLint 통과.
- Next.js 프로덕션 빌드의 컴파일·타입 검사·페이지 생성 통과.
- 인증된 브라우저 수동 검증은 남아 있다.
- 계약 청구일·납부일 설정과 계약 상세 이력은 이번 변경에 포함하지 않았다. 기존 갱신·상태 변경에 대한
  API의 날짜 검증 및 청구 생성 동작은 변경하지 않았다.
