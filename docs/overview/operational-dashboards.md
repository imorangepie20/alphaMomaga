# 자산·점유율·수익 현황 실데이터 전환

## 원인

세 하위 대시보드는 API를 조회하지 않고 영어 템플릿의 상수 배열만 표시했다.
자산 수, 공실 수, 입퇴실 건수와 수익·성장률이 실제 운영 기록과 무관했다.

## 변경

- `dashboard/portfolio`: 등록 자산·임차인, 기준일 유효 계약, 30일 내 만료 계약,
  유형별 자산 구성과 자산별 운영 내역을 표시한다.
- `dashboard/occupancy`: 입력 점유율 평균, 유효 계약, 만료 예정, 점유율 미등록
  자산 수와 자산별 비교 표를 표시한다.
- `dashboard/revenue`: 청구월 선택, 확정 청구·배분 수납·미수·수납률과 자산별
  청구 건수 및 연체 건수를 표시한다. 수납 원장으로 이동할 때 선택 월을 유지한다.
- 제목과 경로 표시를 한국어로 통일하고 공통 테마 컴포넌트를 사용한다.
- 조회 오류·권한 부족·인증 만료는 별도 오류 상태이며 예시나 0원으로 대체하지 않는다.
- 기존 데이터와 인증·수납 변경 API는 변경하지 않았다.

## 집계 기준

- 기준일은 서버에서 한 번 계산하는 서울 날짜다.
- 유효 계약은 `Active`이고 시작일 이상 종료일 이하인 계약이다.
- 점유율은 0~100 범위의 유효한 입력 비율만 단순 평균한다. 등록 임차인 수를
  점유 호실 수로 간주하지 않는다. 호실 총수와 입퇴실 이력이 없어 공실 호실 수,
  가중 점유율, 신규 입주·갱신·퇴거 추이는 아직 계산하지 않는다.
- 금액은 선택 청구월의 `Draft`와 `Cancelled`를 제외한다. 연결 자산이 없는
  확정 청구도 확인 필요 행으로 남겨 합계에서 누락하지 않는다.
- 수납은 해당 청구에 배분된 금액이며 입금일 기준 월 현금흐름이나 순이익이 아니다.
  전년 성장률과 비용 차감 이익은 근거 데이터가 없으므로 표시하지 않는다.
- 확정 청구가 없으면 수납률은 산출 불가이며 100%로 표시하지 않는다.

## 검증

- 웹 전체 테스트 103개 통과: 날짜 유효성 집계, 빈 데이터, 초안·취소·다른 월 제외,
  연결 자산 누락 방지, 월별 링크, 조회 실패 및 권한 오류 표시 포함.
- 변경 파일 ESLint와 `npm.cmd run build --prefix web` 통과.
- 인증된 Cloudflare 브라우저에서 데스크톱·모바일 시각 검증은 미실행이다.

## 메인 대시보드 전환 (2026-09-05)

- `dashboard/real-estate`에도 템플릿 평가액·증감률·추천 자산·담당자·차트가 남아 있었다.
  실제 자산 수, 유효 계약, 30일 내 만료, 미완료 업무 및 현재 청구월 수납 요약으로 교체했다.
- 수납 조회 실패·권한 부족은 수납 영역에서 안내하고 나머지 운영 현황은 유지한다.
- 긴급 점검, 기한 초과, 예정일 순으로 미완료 업무를 정렬해 최대 8건 표시한다.
  완료 기록은 제외하며 전체 유지보수·점검 및 계약 갱신 화면으로 연결한다.
- 실제 확정 청구액 순 상위 8개 자산의 청구·수납·미수 막대그래프를 추가했다.
  공통 금액 척도와 개별 금액·항목명·스크린리더 설명을 제공한다.
- 입력 점유율이 낮은 8개 자산을 0~100% 막대그래프로 비교한다.
  미등록 값은 제외하고 입력값이라는 한계를 표시한다. 가짜 과거 추이는 생성하지 않는다.
- 자동 검증: 웹 110개 테스트 통과. 그래프 금액·초안 제외·접근성 설명,
  기한 초과·우선순위·조회 실패·수납 권한 오류의 부분 표시 포함.
- 변경 파일 ESLint 및 그래프 추가 후 프로덕션 빌드 통과.
- 기존 템플릿 컴포넌트 파일은 다른 예제에서 사용할 수 있어 삭제하지 않고 메인 연결만 제거했다.
- 인증된 브라우저에서 실제 데이터 및 모바일 시각 검증은 아직 수행하지 않았다.

## 후속 데이터 모델

호실 마스터와 계약별 입퇴실·갱신 이력을 도입한 뒤 실제 호실 기반 점유율을
구현한다. 비용 원장이 없는 현재 수납 지표를 순이익으로 확대 해석하지 않는다.
