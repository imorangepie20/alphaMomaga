# Phase 28: Inspections PUT 검증 강화

## 목표
점검 기록 수정 시 잘못된 완료 상태가 메모리 저장소에 남지 않도록 업데이트를 원자적으로 검증합니다.

## 변경 사항

- `InspectionsService.update()`는 빈 입력을 거부합니다.
- 메모리 저장소에서 기존 점검 기록을 직접 변경하지 않고 후보 객체를 생성합니다.
- `validateInspection()` 통과 후에만 배열의 기존 기록을 교체합니다.
- 완료 상태에는 유효한 `completedAt`이 필요하며, 검증 실패 시 기존 상태가 보존됩니다.
- 데이터베이스 경로의 트랜잭션과 감사 로그 흐름은 유지됩니다.

## 테스트

- 유효한 완료 상태와 완료일 업데이트
- 완료일 누락 시 기존 상태 보존
- 빈 입력 거부
- 존재하지 않는 점검 기록 거부

검증 결과: 전체 18개 테스트 파일, 125개 테스트 통과 및 TypeScript 빌드 성공.
