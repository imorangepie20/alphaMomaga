# 공통 헤더 정리

- 검색은 실제 동작 범위에 맞춰 '페이지 검색'으로 표시하고 폭을 줄였다.
  모바일은 아이콘 버튼으로 표시한다. Ctrl/Cmd+K 동작은 유지하고 고정 Mac 단축키 표시는 제거했다.
- 사용자 이름과 이니셜이 중복되던 계정 영역은 사용자 아이콘과 이름 1회 표시로 정리했다.
  클릭 즉시 로그아웃하던 동작 대신 테마 계정 메뉴에서 설정·로그아웃을 선택한다.
- 사용자 지적에 따라 실제 기능이 없는 알림 버튼을 공통 헤더에서 제거했다.
  기존 알림 컴포넌트의 예시 데이터 및 가짜 미확인 건수도 제거했다.
- 로그아웃은 Auth0 인증 경로이므로 일반 브라우저 이동을 유지한다.
- 계정 메뉴 및 인증 링크 집중 테스트 8개와 변경 파일 린트 통과.
- 웹 전체 144개 테스트 및 프로덕션 빌드 통과.
- 인증된 브라우저 시각 검증은 미실행이다.
