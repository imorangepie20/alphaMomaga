# 임차인 월별 수납 조회 개선

## 원인

임차인 화면은 청구월을 표시하지만 월 선택 기능이 없었다. 임차인 ID를 키로 한 Map이 마지막
청구만 남겨 다중 계약의 금액이 누락됐으며, 상단은 임차인 수 대신 청구 건수를 집계했다.

## 변경

- 청구월 선택과 조회를 제공한다. 유효하지 않은 월은 안내와 함께 현재 서울 청구월로 대체한다.
- `summarizeTenantCharges`를 목록과 상단 지표에서 같이 사용한다. 선택한 월의 모든 확정 청구를
  임차인별로 합산하며 초안과 취소는 금액에서 제외한다.
- 연체 미수가 있으면 연체를 우선하고, 미수와 수납이 함께 있으면 부분 납부이다. 확정 청구가 모두
  납부되어도 승인 대기 초안이 있으면 승인 대기로 표시한다. 납부 완료·연체 지표는 임차인 인원수이다.
- 자산명 표시와 검색·자산·납부 상태 필터를 추가했다. 지표는 필터와 무관한 전체 임차인 기준이다.
- 청구 내역 모달에서 모든 개별 청구의 납기일·금액·상태를 확인한다. 초안·취소는 개별 내역에는 남기되
  합계에서 제외한다. 같은 월 수납 원장과 계약 페이지로 이동할 수 있다. 연결 대상 페이지 전체가 열리며
  특정 임차인 필터를 전달하지는 않는다.
- 임차인과 자산 조회 실패 시 예시 데이터를 반환하지 않고 오류를 표시한다.
- 기본 정보 수정 폼은 화면 높이 제한과 중복 제출 방지를 적용했다. 임차인 임대료와 계약 임대료의
  별도 저장 구조는 이번 변경에서 수정하지 않았다.

## 검증

- 웹 전체 테스트 84개 통과 후 청구월 선택·잘못된 월 테스트 2개 추가 검증 통과.
- 다중 청구 합계, 다른 월·임차인 제외, 초안·취소 제외, 혼합 상태 우선순위, 필터와 개별 내역을 검증했다.
- 변경 파일 ESLint 통과. 인증된 Cloudflare 화면 수동 검증은 남아 있다.
- Next.js 프로덕션 빌드 통과(컴파일·타입 검사·페이지 생성).
