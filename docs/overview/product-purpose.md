# 앱 주 목적

## 목적

Alpha Momega는 임대 관리자가 자산, 임차인, 계약, 월별 청구와 수납, 연체,
정비 및 점검을 하나의 업무 흐름으로 관리하는 운영 시스템이다.

이 앱의 기준 업무 흐름은 다음과 같다.

~~~text
property -> tenant -> contract -> monthly charge -> payment -> maintenance -> inspection
~~~

## 운영 원칙

- 화면의 상태, 수치, 알림은 임시 fixture 상태가 아니라 실제 업무 데이터와
  기준일에 근거해야 한다.
- 월별 수납 상태는 반드시 기준월, 납부기한, 청구 금액, 수납 금액, 미납 잔액과
  함께 표시한다.
- 활성 계약을 기준으로 월 청구 초안을 자동 생성하고, 관리자는 계약 변경,
  할인, 공실, 중도 입퇴거 등 예외를 검토한 뒤 확정한다.
- 납부기한이 지난 미납 청구는 자동으로 연체 상태가 되며, 부분 납부와 조정
  내역도 원장에 남긴다.
- 모든 변경은 역할 기반 권한, 유효성 검증, 감사 기록, 재조회 가능한 이력으로
  운영한다.

## 제품 판단 기준

새 기능이나 화면을 추가할 때 다음 질문에 답하지 못하면 우선순위를 낮춘다.

1. 관리자가 월별 미수금, 계약 위험, 현장 업무 위험을 더 빨리 판단할 수 있는가?
2. 데이터가 자산부터 수납과 현장 업무까지 일관된 관계를 유지하는가?
3. 기준월과 상태 변화의 근거를 나중에 감사하거나 설명할 수 있는가?
